The half that needs no model

Stet is a plugin for Claude Code, and half of it never needs the model at all. Is this word spelled two ways across your project. Does this figure still match the command that produced it. Was this paper retracted.

Nobody has to read anything to answer those. Twenty-five commands ship as a CLI with no dependencies. They run in your build. A build that fails does not ship.

stet sums, run on this repository 
7 relations across 61 files.

7 consistent, 0 wrong, 0 worth a look
NOT CHECKED  2 relations inside quotation
             marks, 1 on a marked line

Every command tells you what it skipped. Say nothing and a person reads it as nothing to do, which is a different thing and not true.

One

What each one catches

Ten of them are the checks. The other fifteen are what the checks stand on: what content exists, who owns it, what the style sheet decided, what to set on a file. One of the fifteen is refresh. It changes a stale figure and leaves every other word alone.

Every one was run over this repository and tuned until it stopped crying wolf. A check that fires on work you got right is a check you switch off. Then it protects nothing.

stet help <command> prints the full reference for any of them.

Two

Why this is worth a build step

Somebody counted all four of these, and none of them is about your website. They are about journals, because journals are where anyone bothered to count. Your pages rot the same way.

Does any of that reach a pricing page? The link row does. A URL that still returns 200 has not necessarily kept the sentence you cited it for. The page looks fine. Nothing on it says the paragraph you quoted came out two years ago. That is the same failure as a product name spelled two ways across forty files, and the same reason nobody notices.

So standing writes down what a source said the first time you cited it, and tells you what has changed since.

Three

Running it

What does it cost to set up? One file. stet.config.json says which files are your words. It can also say where a figure comes from, which is a shell command.

Stet touches your words and nothing else. No components, no routing, no CSS. Put it on Next, Astro, Hugo or a folder of Markdown and it behaves the same, and the checks that need no network never open one.

In a build 
# everything, exit 1 on a disagreement
stet audit

# or pick the ones you care about
stet check && stet sums && stet standing

# one file, against your own voice
stet measure docs/pricing.md

The CLI ships inside the plugin, and node bin/stet.mjs from a clone works the same.
